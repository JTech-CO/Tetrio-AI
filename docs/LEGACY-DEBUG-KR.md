# BASIC/RAPID 및 공통 런타임 디버깅

2026-09-21. TURBO 외 일반 코드도 조사·수정하라는 후속 요청에 따라 백서의 기존 모드 동결 범위를 확장했다.

## 수정 사항

- NEXT 인식에서 null을 제거해 뒤의 피스를 앞당기던 문제를 수정했다. 연속으로 확인된 앞부분만 사용하고 최소 두 피스를 읽기 전에는 입력하지 않는다.
- 새 스테이지 지문을 매 프레임 다시 초기화해 변경을 확정하지 못하던 디바운스를 수정했다. 흔들림에 따른 수치는 여전히 픽셀 기반 추정이다.
- BASIC 탭 및 RAPID 정밀 입력은 keydown 실패 시에도 finally에서 keyup을 보낸다. 종료 시 눌린 키를 해제하고 중복 소켓 종료를 막는다. 중간 취소에서는 남은 키와 하드드롭을 보내지 않는다.
- 모드 전환 시 RAPID 전용 설정을 제거하고 사용자 JPEG 품질과 명시적 postdrop 값을 유지한다. 전환은 피스 실행 경계에서 수행한다.
- 초기 보정 실패 시 다른 해상도의 고정 좌표로 실행하지 않는다. 연결 후 초기화 실패는 소켓을 닫는다. 기존 보정이 있으면 일시적인 검출 실패 시 보존한다.
- LEVEL COMPLETE 텍스트를 보드로 해석하지 않고 현재 피스 추적을 다시 시작한다.
- 예측 보드 불일치 시 34ms 후 최대 두 번 재관측한다. 이전 프레임으로 계산한 파이프라인 수는 폐기하고 새 관측에서 다시 계산한다. 지속 불일치는 숨기지 않고 mispredicts에 센다.
- 입력 불가능한 보드에서도 60초 정체 제한을 적용하고, 오류로 루프를 나가도 진행 중인 캡처를 정리한다.
- 복구 실패 카운터를 보정 성공만으로 초기화하지 않는다. 실제 플레이가 진행돼야 초기화하며, 연속 8회 실패는 종료 코드 1을 반환한다. 반복 렌더러 열화도 동일하게 제한한다.
- 누락·오타·범위 초과 CLI 인수를 앱 연결 전에 거부한다. restart-mins는 유한한 음이 아닌 소수도 지원한다.

## 검증

자동 테스트 70개 통과. 기존 보드/AI 및 TURBO 테스트에 키 해제·취소, 옵션 유지, NEXT 공백,
스테이지 디바운스, 전환 화면, CLI 검증, 재관측을 추가했다.
감독 루프는 별도 Node 프로세스에서 CDP/앱 연결을 모킹하여 일반 오류와 열화 오류 각각 8회 후 실패 종료하는지 검사한다.

실기동 원본은 [legacy-smoke-2026-09-21.json](legacy-smoke-2026-09-21.json)에 기록한다.
기존 사용자 비디오 설정에서 BASIC/RAPID를 순차 실행하므로 피스열과 보드가 다른 스모크 테스트다.
오배치 통계는 화면 예측 불일치 추정이며 실제 오배치와 동일하지 않다.
재관측 도입 전 기록도 보존하며 전후 결과를 통제된 정확도 비교로 해석하지 않는다.

| 최종 실기동 | 피스 | 시간 | PPS | 지속 예측 불일치 | 재관측 | 피스 재동기화 |
|---|---:|---:|---:|---:|---:|---:|
| BASIC | 100 | 39.837 | 2.510 | 0 | 7 | 0 |
| RAPID | 100 | 25.929 | 3.857 | 6 | 22 | 3 |

두 모드 모두 100피스 완료 및 80피스 재보정 통과. RAPID의 지속 예측 불일치 6회와 재동기화 3회는 남아 있다. 일반 모드의 무오배치 또는 장시간 내구성까지 검증했다고 주장하지 않는다.

추가로 생성 영역 위쪽 2.5행을 캡처해, 보이는 20행 위에 머무는 피스도 모양으로 식별한다. 레벨 전환 뒤 피스 미검출로 대기가 길어지는 문제를 보완하며, 실제 화면 및 빈 이미지 테스트를 포함했다.
