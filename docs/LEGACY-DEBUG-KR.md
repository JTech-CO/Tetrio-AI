# BASIC·RAPID 안정성 장치

BASIC과 RAPID는 피스를 하나 둘 때마다 화면을 읽습니다. 화면 인식이 잠깐 틀리거나 앱이 멈춰도 계속 플레이하도록 아래 장치를 둡니다. 낯선 용어는 [README의 용어](../README.md#용어)를 보세요.

| 상황 | 동작 |
|---|---|
| 화면이 직전 예측과 다름 | 한 번 다시 읽습니다. 반쯤 그려진 프레임일 수 있어서입니다. 그 프레임으로 계산한 수는 버리고, 계속 다르면 보이는 대로 이어서 둡니다 |
| NEXT 일부가 안 읽힘 | 첫 칸만 읽히면 계속 둡니다. 빈 HOLD에 넣는 수만 두 칸이 필요합니다 |
| 필드 위치가 어긋날 수 있음 | 80피스마다 필드를 다시 찾습니다. 찾지 못하면 이전 값을 유지하고, 처음부터 못 찾으면 추측 좌표로 시작하지 않습니다 |
| 60초 동안 피스를 못 읽음 | 다시 연결해 이어 가고, 또 실패하면 앱을 재시작해 ZEN으로 다시 들어갑니다 |
| 오류가 연속 8회 | 복구할 수 없다고 보고 종료 코드 1로 끝냅니다. 실제로 피스를 두어야 횟수가 초기화됩니다 |
| 종료·연결 끊김 | 종료할 때 눌린 키를 모두 뗍니다. 끊겼다가 새로 연결할 때도 모든 키를 한 번 뗍니다 |
| 잘못된 명령행 인수 | 앱에 연결하기 전에 거부합니다 |

실측 기록은 [플레이 로그 모음](PLAY-LOGS-KR.md)에 있습니다.
