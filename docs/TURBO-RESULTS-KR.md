# TURBO 구현·검증 요약

2026-09-21 · Windows / Node.js 25.9.0 / TETR.IO Desktop 10.0.0 · 뷰포트 1295×999, DPR 2.

## 최종 결과

**500피스 / 93.940초 = 5.323 PPS로 합격.** 의심 피스·재동기화·입력 오류·폴백 모두 0회.
[실측 JSON](turbo-validation-500-final-2026-09-21.json). 자동 테스트는 70개 통과했다.

연결·초기 보정·준비 주행 60피스는 측정에서 제외하고, 실행 중 검증·복구·키 해제 시간은 포함했다.
합격 조건은 500피스 이상, 의심 피스를 제외한 PPS ≥5, 의심 피스 ≤3%, 강제 재동기화 ≤1%, 입력 오류·폴백 0회다.

**한계:** 최종 구간에는 레벨 전환이 없었고, 최종 코드의 1,000피스 완주는 미검증이다.
이전 버전의 장기 성공 이후에도 전환·캡처 지연으로 실패한 시도가 있었다. 다른 환경에서 같은 속도나 무오배치를 보장하지 않는다.
의심 피스는 불일치 검증 구간 전체의 피스 수이며, 실제 오배치 수와 같지 않다.

## 핵심 구현

- **예측·검증:** 최대 2피스 계획, 별도 캡처 연결, 검증 완료 전 후속 입력 차단. NEXT 공백은 건너뛰지 않는다.
- **입력:** 실측 보정에 통과한 기능만 사용한다. 합격 프로필은 스폰 65ms와 회전·첫 이동 동시 입력이며, 타이머 지연 시 키 펄스를 압축하지 않는다.
- **화면·복구:** 화면 효과를 임시 고정하고 원래 설정을 복원한다. 레벨 전환 문구와 숨겨진 생성 영역을 읽으며, 재동기화는 전체 상태가 세 번 연속 일치해야 재개한다.
- **안전 제한:** 400ms 검증 제한, 지속 불일치·입력 오류 시 재동기화 또는 RAPID 폴백. 스폰 전 DAS 충전은 비활성화다.

코드는 [예측 루프](../src/turbo.js), [입력 모듈](../src/input/), [비전](../src/vision/vision.js)에 있다.
**Jev는 미도입:** 로컬 개선으로 목표를 달성했고 추가 효과를 입증하지 못했다. Jev의 현재 API·실성능을 별도로 검증한 것은 아니다.
